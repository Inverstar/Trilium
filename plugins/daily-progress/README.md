# 关联进展 (Daily Progress Widget)

Trilium Notes 右侧面板小部件（Right Panel Widget），用于在当前笔记的右侧栏自动汇聚、精准展示与当前笔记相关联的所有历史进展和日记卡片。

---

## 💡 功能特性

- **多维智能匹配**：
  1. **`~topic` 关系**：自动查找配置了 `~topic` 关联到当前笔记的笔记。
  2. **`@提及 / 反向链接` (Backlinks)**：匹配正文中通过 `@` 引用了当前笔记的记录。
  3. **同名进展笔记**：匹配其他目录（如每日日记）下的同名子任务/进展笔记。
- **排除干扰**：严格排除当前正在查看的笔记自身以及搜索类型笔记。
- **时间线倒序排列**：自动提取日期（优先从父级日记标题、`#dateNote` 标签、笔记标题或创建时间中提取），按日期从新到旧排序。
- **卡片流排版**：自适应高度、展示关联类型标签（`🏷️ topic 关联`、`🔗 @引用`、`📄 同名进展`）、支持点击标题一键跳转至对应笔记、正文片段完整呈现。
- **手动刷新**：顶部面板支持快速点击一键重新刷新匹配。

---

## 📦 安装与使用方法

1. 打开 **Trilium Notes**。
2. 新建一个笔记：
   - **标题**：例如 `关联进展组件` 或 `Daily Progress Widget`
   - **类型**：选择 **JS Frontend**（前端脚本）
3. 为该笔记添加标签属性（Attributes）：
   - `#widget`
4. 将 [`daily-progress-widget.js`](./daily-progress-widget.js) 中的所有代码完整复制并粘贴到该笔记的内容编辑器中。
5. 保存笔记并重新加载前端页面（快捷键 `Ctrl+R` / `F5`，或切换当前笔记）。
6. 在右侧侧边栏中即可看到 **📅 关联进展** 面板。
