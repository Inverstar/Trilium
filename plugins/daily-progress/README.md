# 关联进展 (Daily Progress Widget)

Trilium Notes 右侧面板小部件（Right Panel Widget），根据当前笔记的 `#topic` 属性值作为**唯一标准**，自动在右侧栏精准汇聚并展示其他所有具有相同 `#topic` 属性值的笔记卡片。

## 💡 V2 核心机制与升级特性

1. **原样富文本展示与图片渲染**：
   - 完整保留正文的排版格式（段落、各级标题、引用、列表、代办复选框、表格、代码块等）。
   - 彻底解决旧版无法显示图片的问题，自动解析并渲染笔记中的内嵌图像（`api/images/...`），限制宽度自适应侧边栏，支持鼠标悬浮放大及点击全屏大图预览。
   - 继承 Trilium 原生 `.ck-content` 样式标准，与亮色/暗色主题无缝融为一体。
2. **列表式折叠与展开 (Accordion)**：
   - 每张卡片均支持手风琴式折叠收起：
     - **收起态**：紧凑展示日期标签、`#topic` 标签、笔记标题和单行摘要。
     - **展开态**：完整呈现正文、内嵌图片及操作工具。
   - 顶部工具栏提供 **「展开全部」** 与 **「收起全部」** 一键操作，兼顾速览与精读。
3. **就地查看与敏捷编辑**：
   - 卡片右上角配备「编辑」按钮，点击后立即就地展开富文本编辑器。
   - 提供轻量格式工具栏（粗体、斜体、下划线、删除线、各级标题、列表、代码块等），并支持切换至 HTML 源码模式。
   - 具备双层持久化保存保障（优先调用 `api.runOnBackend`，自动降级兼容 `PUT /api/notes/:noteId/data` REST API）。
   - 保留「在主编辑区打开」图标链接，方便随时跳转至主窗口全功能编辑。
4. **严格唯一匹配标准**：
   - 读取当前正在查看笔记的 `#topic` 属性值（例如当前笔记配置了 `#topic=PKM`）。
   - 检索库中除了当前笔记外、同样拥有该属性且属性值完全相同的其他笔记（即 `#topic=PKM`）。
   - 排除当前笔记自身，并按时间线倒序排版。

## 📦 安装与使用方法

1. 打开 **Trilium Notes**。
2. 新建一个笔记：
   - **标题**：例如 `关联进展面板 (v2)`
   - **类型**：选择 **JS Frontend**（前端脚本）
3. 为该笔记添加标签属性（Attributes）：
   - `#widget`
4. 将 [`daily-progress-widget-v2.js`](./daily-progress-widget-v2.js)（推荐）中的所有代码完整复制并粘贴到该笔记的内容编辑器中。
5. 保存笔记并重新加载前端页面（快捷键 `Ctrl+R` / `F5`）。
6. 在任一笔记上添加属性（如 `#topic=PKM`），右侧面板即可自动展开展示其他同样为 `#topic=PKM` 的笔记。
