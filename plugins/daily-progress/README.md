# 关联进展 (Daily Progress Widget)

Trilium Notes 右侧面板小部件（Right Panel Widget），根据当前笔记的 `#topic` 属性值作为**唯一标准**，自动在右侧栏精准汇聚并展示其他所有具有相同 `#topic` 属性值的笔记卡片。

---

## 💡 核心机制与特性

- **严格唯一匹配标准**：
  - 读取当前正在查看笔记的 `#topic` 属性值（例如当前笔记配置了 `#topic=PKM`）。
  - 检索库中除了当前笔记外、同样拥有该属性且属性值完全相同的其他笔记（即 `#topic=PKM`）。
  - 已删除所有其他检索途径（如 `@提及引用`、`~topic` 目标关系、同名笔记等），仅以此为唯一标准。
- **排除当前笔记自身**：即便当前笔记本身具有 `#topic`，也不会在面板中自我展示。
- **友好提示**：
  - 若当前笔记未设置 `#topic` 属性，面板会提示添加 `#topic` 属性。
  - 若库中暂无其他相同 topic 笔记，给出明确的空状态指引。
- **时间线倒序排版**：智能识别日期（优先从父级日记标题、`#dateNote` 标签、笔记标题或创建日期中识别），按从新到旧时间流排序。
- **卡片流排版**：自适应高度、展示属性标签（`🏷️ #topic=...`）、支持点击标题一键跳转至对应笔记、正文片段自适应展开展示。
- **一键刷新**：顶部面板支持快速点击重新刷新匹配。

---

## 📦 安装与使用方法

1. 打开 **Trilium Notes**。
2. 新建一个笔记：
   - **标题**：例如 `关联进展面板` 或 `Daily Progress Widget`
   - **类型**：选择 **JS Frontend**（前端脚本）
3. 为该笔记添加标签属性（Attributes）：
   - `#widget`
4. 将 [`daily-progress-widget.js`](./daily-progress-widget.js) 中的所有代码完整复制并粘贴到该笔记的内容编辑器中。
5. 保存笔记并重新加载前端页面（快捷键 `Ctrl+R` / `F5`）。
6. 在任一笔记上添加属性（如 `#topic=PKM`），右侧面板即可自动展开展示其他同样为 `#topic=PKM` 的笔记。
