# 关联进展 (Daily Progress Widget)

Trilium Notes 右侧面板小部件（Right Panel Widget），支持根据当前笔记的 `#topic`、`#theme`、`#tag` 多维度属性组合以及布尔逻辑表达式（与、或、非），精准聚合展示相关笔记卡片，并支持就地富文本编辑与持久化保存。

## 💡 V3 核心机制与特性

### 1. 多维度属性与布尔逻辑组合筛选
- **支持三维属性**：同时识别当前笔记的 `#topic`、`#theme`、`#tag` 属性。
- **支持丰富的逻辑表达式**：
  - **与（AND）**：`与`、`且`、`and`、`AND`、`&&`、`&`、`+` 或 空格。
  - **或（OR）**：`或`、`or`、`OR`、`||`、`|`。
  - **非（NOT）**：`非`、`not`、`NOT`、`!`、`~`。
  - **括号分组**：中英文小括号 `( )` 与 `（ ）`，支持任意多层嵌套。
  - **自然语言连续表达**：例如 `A与C非B`，系统将智能解析为 `(A 且 C) 且 (非 B)`。
- **典型表达式示例**：
  - `A与C或B`：匹配包含 A 且包含 C 的笔记，或者包含 B 的笔记。
  - `A与C非B`：匹配包含 A 且包含 C、但**不包含** B 的笔记。
  - `(A 或 B) 与 C`：匹配属于 A 或 B，并且同时包含 C 的笔记。
  - `topic=A 与 tag=C 非 theme=B`：支持精确指定属性维度前缀。

### 2. 交互式表达式控制台 (Filter Console)
- **快捷属性徽章**：顶部一键罗列当前笔记的所有 `#topic`、`#theme`、`#tag` 徽章，点击即可将该属性插入到表达式输入框。
- **操作符快捷按钮**：提供 `与`、`或`、`非`、`(`、`)` 快捷插入按钮。
- **常用预设模板**：提供「全包含 (AND)」、「任一包含 (OR)」、「A与C非B」等一键切换模板。
- **实时语法校验与自然语言释义**：实时显示当前表达式的语法解释（例如：`规则: ((包含「A」 且 包含「C」) 且 不包含(包含「B」))`），错误时提供友好提示。
- **规则持久化**：点击「设为默认」可将当前自定义筛选表达式一键保存至该笔记的 `#progressFilter` 属性中，下次打开自动载入。

### 3. 原样富文本展示与图片渲染
- 完整保留正文的排版格式（段落、各级标题、引用、列表、待办复选框、表格、代码块等）。
- 自动解析并加载笔记内嵌图像（`api/images/...`），自适应右侧栏宽度，支持鼠标悬浮放大及点击全屏大图预览（Lightbox）。
- 继承 Trilium 原生 `.ck-content` 样式标准，与明暗主题自适应融合。

### 4. 列表式折叠与展开 (Accordion)
- **收起态**：精致单行摘要，并按维度分类展示 `topic`（绿色）、`theme`（紫色）、`tag`（橙色）专属标签。
- **展开态**：完整呈现富文本正文、图片与就地编辑工具。
- 顶部提供「展开全部」与「收起全部」一键操作。

### 5. 就地查看与敏捷编辑
- 卡片右上角配备「编辑」按钮，点击就地展开富文本编辑器，无需离开侧边栏。
- 内置轻量格式工具栏（粗体、斜体、下划线、删除线、各级标题、列表、代码块等），并支持切换 HTML 源码模式。
- 双层持久化保存（优先调用 `api.runOnBackend`，自动降级 `PUT /api/notes/:noteId/data` REST API）。

## 📦 安装与使用方法

1. 打开 **Trilium Notes**。
2. 新建一个笔记：
   - **标题**：例如 `关联进展面板 (v3)`
   - **类型**：选择 **JS Frontend**（前端脚本）
3. 为该笔记添加标签属性（Attributes）：
   - `#widget`
4. 将 [`daily-progress-widget-v3.js`](./daily-progress-widget-v3.js)（推荐）中的所有代码完整复制并粘贴到该笔记的内容编辑器中。
5. 保存笔记并重新加载前端页面（快捷键 `Ctrl+R` / `F5`）。
6. 在任一笔记上添加属性，例如：
   - `#topic=PKM`
   - `#theme=Frontend`
   - `#tag=React`
7. 右侧面板将自动展开并匹配相关笔记，你可以在面板顶部的筛选器中自由编写或点击组合表达式，如 `PKM 与 React 非 Frontend`！
